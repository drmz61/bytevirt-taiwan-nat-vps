## 什么是 Taiwan NAT VPS：先搞清楚再掏钱

NAT VPS 的核心逻辑其实就一句话：**多人共享一个 IPv4 地址，靠端口转发对外提供服务**。

传统 VPS 你买一台，给你一个独立公网 IPv4，全世界都能直接 ping 到。NAT VPS 不一样，它是好几个用户共用同一个 IPv4，每个人分到 20 个端口（端口号通常是随机分配或者从某个区间里挑），你想让外面访问你机器上的 80 端口，得通过 `共享IP:你分配到的端口` 这种形式来访问。

听起来好像挺别扭？但好处也明显：

- **便宜**：因为 IPv4 资源紧张，独立 IPv4 成本高，共享之后单价能压到年付几美元
- **流量给得大方**：NAT 套餐通常流量配额比同价位独立 IP 套餐多
- **IPv6 是独立的**：每人一段 /80 甚至 /64，IPv6 那条路是畅通的

而 "Taiwan" 这个前缀，就是说机房在台湾。台湾节点对大陆、日韩、东南亚的延迟都比较友好，尤其是 HiNet 这条线，在中文圈里口碑一直不错。

> ⚠️ 一个关键点：ByteVirt 官方明确写了 **"IPv4 is blocked by GFW by defaults, please use IPv6"**。意思是默认情况下，NAT 套餐的共享 IPv4 从大陆是访问不通的，得靠 IPv6 走通。这点买之前一定要心里有数。

## 常见问题 FAQ

**Q1：Taiwan NAT VPS 能用来建站吗？**

可以，但更适合轻量站点。20 个端口够你跑 Web + SSH + 几个其他服务。如果是高流量站或者需要 SSL 证书绑定独立 IP，建议选 TW-ISP 系列。

**Q2：IPv6 怎么用？我本地没 IPv6 怎么办？**

NAT 套餐会给一段 /80 IPv6，你可以直接用 IPv6 地址访问。如果你本地网络没 IPv6，可以：用支持 IPv6 的云服务器做跳板；或者用 Cloudflare 之类 CDN 套一层；再不行就别选 NAT，直接上 TW-ISP。

**Q3：超流量后会怎样？**

端口速度被限到 1Mbps，基本等于没法正常用。所以选套餐时流量要留余量，或者监控消耗及时升级。

**Q4：能换机房吗？**

不能。下单时选了台湾就是台湾，想换其他位置得另外下单。这点买之前一定想清楚。

**Q5：NAT-KVM 和 NAT-LXC 怎么选？**

KVM 是完整虚拟化，隔离性好，能装任意系统，适合跑 Docker、开发环境；LXC 是容器虚拟化，更轻量更便宜，适合纯学习、轻量任务。预算紧选 LXC，要折腾选 KVM。

**Q6：优惠码能叠加吗？**

通常不能叠加，一个订单用一个码。下单前对比下哪个码折扣大，选最划算的。
